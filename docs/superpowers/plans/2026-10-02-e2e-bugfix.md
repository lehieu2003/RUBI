# IceFlow Bug-Fix Batch Implementation Plan (20 bugs, 2026-10-02)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix toàn bộ 20 bug tìm thấy từ vòng E2E test (crash, sai dữ liệu công nợ/kho, tính năng driver-link chết, impersonation catch-22, sai số liệu "hôm nay", polish UI/a11y).

**Architecture:** Fix surgical theo root cause đã xác minh (spec ghi rõ file:line). Thêm 1 pure helper `unwrapEnvelope` dùng chung thay idiom copy-paste. Không đổi schema DB. Test theo convention hiện có của repo: source-pattern tests (`readFileSync` + `assert.match`) + unit test thuần cho hàm importable.

**Tech Stack:** Next.js 15 App Router, React 19, TanStack Query 5, Prisma 6, node:test + node:assert (runner `tests/run-tests.ts`).

**Spec:** `docs/superpowers/specs/2026-10-02-e2e-bugfix-design.md`

## Global Constraints

- Không sửa `prisma/schema.prisma`, không tạo migration.
- Không đụng: `src/lib/db.ts` (tenant extension), `src/lib/rbac/permissions.ts` (bảng route permissions), logic bên trong reconcile transaction (`src/app/api/orders/[id]/reconcile/route.ts`).
- Style: match code hiện có (double quotes trong API routes, hex-token classes `bg-[#004a99]`, toast qua `@/components/dashboard/toast`).
- Mọi API response mới giữ envelope `apiSuccess/apiError` — NGOẠI TRỪ `/api/d/[token]` (page client đọc `{orders, driverName}` top-level, spec B1).
- Commit theo conventional commits như lịch sử repo (`fix(...)`, `feat(...)`).
- Dev server đang chạy ở `:3001` (env local DB). `npm test` không cần DB.
