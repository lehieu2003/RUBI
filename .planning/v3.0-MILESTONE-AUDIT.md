## Cross-Phase Integration

Source inspection shows the expected wiring exists for several flows:

- `src/middleware.ts` reads `data.subscription` and fails closed when subscription status cannot be verified.

- `src/app/api/payments/confirm/route.ts` now creates `Payment` records.
- Scheduling is wired through Prisma schema, tenant-scoped db extension, `/api/schedule/assignments`, `/schedule`, sidebar, and RBAC tests.

These are still audit gaps because Phase 08 and Phase 08B lack the required post-execution verification artifacts for the corresponding milestone requirements.
