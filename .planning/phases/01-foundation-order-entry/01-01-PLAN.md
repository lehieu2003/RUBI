<task type="auto">
  <name>Task 1: Write Prisma schema for all Phase 1 entities</name>
  <files>prisma/schema.prisma</files>
  <action>
    Create `prisma/schema.prisma` with the following models in order:

1. **Product** — `id` (cuid), `name` (Đá Bi or Đá Viên), `sizeKg` (5/10/20), `unit` (bag/block), `isActive` (bool, default true), `createdAt`/`updatedAt` (DateTime)

2. **Customer** — `id` (cuid), `code` (string, unique, e.g. KH001), `name`, `address`, `phone`, `isActive` (bool, default true), `createdAt`/`updatedAt` (DateTime)

3. **GlobalPrice** — `id` (cuid), `productId` (FK to Product), `pricePerUnit` (Decimal), `updatedAt` (DateTime). Unique constraint on productId.

4. **CustomerPriceOverride** — `id` (cuid), `customerId` (FK to Customer), `productId` (FK to Product), `pricePerUnit` (Decimal), `updatedAt` (DateTime). Unique constraint on [customerId, productId].

5. **Order** — `id` (cuid), `customerId` (FK to Customer), `status` (enum: DRAFT, CONFIRMED, PRINTED, DELIVERED), `total` (Decimal, default 0), `notes` (string, optional), `createdAt`/`updatedAt` (DateTime)

6. **OrderItem** — `id` (cuid), `orderId` (FK to Order), `productId` (FK to Product), `quantity` (Int), `unitPrice` (Decimal), `lineTotal` (Decimal)

Use Prisma's `@@index` on `customerId` for orders table. Use `@default(cuid())` for all id fields. Use `@db.Decimal(10,2)` for all price/decimal fields.
  </action>
  <verify>
    <automated>npx prisma validate --schema prisma/schema.prisma</automated>
  </verify>
