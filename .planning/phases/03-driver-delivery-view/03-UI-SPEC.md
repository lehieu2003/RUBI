## Spacing Scale

Declared values (multiples of 4 as per 8-point grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline micro-padding |
| sm | 8px | Tight element spacing, icon padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, card gaps |
| xl | 32px | Layout gaps, section breaks |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:** None — all touch targets for driver UI must be minimum 44px (not 40px) per D-05 outdoor-optimized requirement. Buttons and tap zones use `min-h-[44px]` minimum.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 500 (medium) | 1.4 |
| Heading | 18px | 700 (bold) | 1.2 |
| Display | 24px | 800 (extrabold) | 1.1 |

**Driver-specific constraints (per D-05: outdoor-optimized, readable in sunlight, wet hands):**
- Body text minimum 16px
- Customer name (heading) minimum 18px bold
- All touch targets readable at arm's length
- No text smaller than 14px anywhere on driver view

## Component Inventory

### DeliveryCard
- **Appearance:** Rounded-2xl card with backdrop blur, border. Pending: `bg-white/5 border-white/10`. Delivered: `bg-emerald-500/5 border-emerald-500/20`
- **Contents:** Order code badge (mono font), customer name (bold 18px), items summary, address (tappable map link), three action buttons
- **States:** PENDING (amber badge), DELIVERED (green badge, card tint)
- **Touch targets:** All buttons minimum 44px height

### ActionButton (Goi dien, Ban do, Da giao)
- **Goi dien:** Blue (`bg-blue-500`), phone icon, `flex-1`
- **Ban do:** Blue (`bg-blue-500`), map icon, `flex-1`
- **Da giao:** Green (`bg-emerald-500`), check icon, `flex-1`, bottom of card

### StatusBadge
- **PENDING:** Amber background (`bg-amber-500/20`), amber text (`text-amber-400`), `Chờ giao`
- **DELIVERED:** Green background (`bg-emerald-500/20`), green text (`text-emerald-400`), `Đã giao`

### StatsCard (header)
- **Pending count:** Amber-tinted card, Clock icon, large bold count
- **Delivered count:** Emerald-tinted card, CheckCircle2 icon, large bold count

### EmptyState
- Truck illustration placeholder
- Heading: `Chào {Tên tài xế}, hiện tại anh không có đơn hàng nào cần giao.`
- `[Làm mới]` button centered below

### RefreshButton
- `[Làm mới]` text button + pull-to-refresh gesture
- Appears in empty state AND as header action

### MapButton
- `[Xem bản đồ]` button in header or between stats and list
- Opens Leaflet map with all delivery dots for this driver
