## Copywriting Contract

| Element | Copy |
|---------|------|

| Action | Label |
|--------|-------|
| Previous week | "<<" or "‹" |

| Today button | "Hôm nay" |
| Clear shift | Click cycles: M -> A -> N -> empty |

## Layout Structure

```
+----------------------------------------------------------+
|  Header: "Lịch trình tuần" + Week navigation (‹ Week › [Hôm nay]) |
+----------------------------------------------------------+
|        | T2   | T3   | T4   | T5   | T6   | T7   | CN    |
|--------|------|------|------|------|------|------|-------|
| Driver1| M    |  A   |  N   |  M   |  A   |  -   |   -   |
| Driver2|  A   |  N   |  M   |  A   |  N   |  M   |   -   |
| ...    | ...  | ...  | ...  | ...  | ...  | ...  |  ...  |
+----------------------------------------------------------+
```

**Grid specs:**
- CSS Grid: `grid-cols-8` (1 col for driver name + 7 cols for days)
- Driver name column: `min-w-[120px]`, left-aligned, sticky
- Shift cells: `square aspect-ratio` (equal width/height for touch)
- Cell interaction: Click to cycle M -> A -> N -> empty
- Week start: Monday (Vietnam ISO standard)
- Responsive: Horizontal scroll on mobile if needed
