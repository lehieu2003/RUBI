  <files>src/app/orders/[id]/page.tsx</files>
  <action>
Read src/app/orders/[id]/page.tsx first.

Fix the print timing issue in handlePrint. Currently it sets showPrintSlip(true) then calls window.print() after 100ms. This is insufficient for React to render PrintSlip to DOM.

Replace the handlePrint function with a useEffect pattern:

```tsx
const [showPrintSlip, setShowPrintSlip] = useState(false);

// Use effect to print after PrintSlip renders to DOM
useEffect(() => {
  if (showPrintSlip) {
    // Wait for React to render PrintSlip to DOM, then print
    requestAnimationFrame(() => {
      requestAnimationFrame(() => {
        window.print();
        setShowPrintSlip(false); // Reset after print
      });
    });
  }
}, [showPrintSlip]);

const handlePrint = () => {
  setShowPrintSlip(true);
};
```

The double requestAnimationFrame ensures the browser has completed layout/paint before the print dialog opens. 100ms is unreliable across different machines.
  </action>

  <name>Task 3: Fix CSS selector for nested .print-slip elements</name>
  <files>src/app/globals.css</files>
  <action>
Read src/app/globals.css first.

The current CSS selector `body > *:not(.print-slip)` only matches direct children of body. But PrintSlip is nested inside a wrapper div with classes `hidden print:block`.

Fix the @media print rules to target .print-slip regardless of nesting depth. Replace the selector:

Before:
```css
body > *:not(.print-slip):not(main) {
  display: none !important;
}
```

After:
```css
/* Hide everything except .print-slip on print - handles nested elements */
body *:not(.print-slip) {
  display: none !important;
}

/* Show only the print slip and its contents */
.print-slip,
.print-slip * {
  display: block !important;
}
```

The new selector `body *:not(.print-slip)` matches ANY descendant of body that is NOT .print-slip, regardless of nesting depth. Then `.print-slip *` ensures all children of the print slip are also visible.
